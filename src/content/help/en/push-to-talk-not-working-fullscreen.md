The push-to-talk key in Komunikator is a **global shortcut**, so it should work even when the game window is focused and in fullscreen. If your team can’t hear you, go through these steps.

1. **Check that push-to-talk is on**

   Open **Settings › Voice & video** and make sure **Speaking mode** is set to **Push-to-talk**, not Voice activity.

2. **Check the key**

   In the same place, look at **Push-to-talk key**. Pick a key the game doesn’t use — a mouse side button is a good choice. Avoid keys next to movement or abilities.

3. **Run both apps with the same permissions (Windows)**

   If the game runs **as administrator** and Komunikator doesn’t, Windows won’t pass your key presses to Komunikator while the game is focused. Run both normally, or both as administrator.

4. **Test your microphone**

   Use **Mic test** in Settings › Voice & video. If the level bar doesn’t move while you hold the key, check the selected **Input device**.

> **First words still cut off?** Komunikator keeps a short buffer before the key press and releases the key 120 ms after you let go. Read more in [Push-to-talk that doesn’t cut off your first words](/blog/push-to-talk-first-words/).
